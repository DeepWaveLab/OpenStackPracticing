# OpenStack 課程章節與歷史紀錄

目前課程從 [Day 0 的 Azure 實驗環境](sprint3-day0-azure-vm.md)開始，使用 Kolla-Ansible 2025.1 部署 OpenStack，接著練習資源管理、Kubernetes 叢集服務、多節點維運與租戶治理。完整順序、先備知識及 Day 0–35 的連結請見[課程總覽](../index.md)。

本目錄也保存前兩次部署嘗試。`day-*` 是 Juju／Charms 路線，`sprint2-*` 是 OpenStack-Helm 路線；它們使用不同的環境與版本，閱讀入口在[前兩次嘗試](../previous-attempts.md)。目前主線的檔名則是 `sprint3-day*`、`sprint4-day*`、`sprint5-day*` 及 `epilogue.md`。

章節中的輸出來自當時的驗證環境。重做時須先確認版本、網路、認證與所需檔案；沒有保存完整建置步驟或沒有驗證過的部分，會在正文交代。範例中的位址、資源名稱與識別碼須依自己的環境替換。
