    親手蓋一朵雲¶

    虛擬機、虛擬網路、雲端硬碟、負載平衡——公有雲的這些能力不是魔法,是一套叫 OpenStack 的開源軟體。AWS 那個層級的東西,你可以自己蓋一朵。

    這個網站帶你從 Azure 的一台空白 VM 開始,把一朵雲從零蓋起來。第二天,你就會對自己的雲下這個指令:

    openstack server create --flavor m1.tiny --image cirros --network net1 vm-cirros

    你的雲,開出它的第一台虛擬機。之後每一天再給它一個新能力:雲端硬碟、負載平衡、秘密保險箱、資源藍圖……直到最後一天,這朵雲甚至能像 AWS 的 EKS 一樣,一行指令長出一整座 Kubernetes——那是課程壓軸,也是我們失敗過兩次才做到的事。

    這些是你這趟旅程會認識的夥伴——OpenStack 每個服務都有官方吉祥物,記臉比記名字快。

    這朵雲能做成什麼¶

    你在公有雲用過的東西,OpenStack 幾乎都有對應的積木——這門課會親手把它們一塊塊拼起來:

    服務 它給你什麼 AWS GCP Azure
    Keystone 身分認證與存取控制 IAM Cloud IAM Entra ID
    Glance VM 映像檔管理 AMI Images Compute Gallery
    Nova 虛擬機生命週期與運算調度 EC2 Compute Engine Virtual Machines
    Neutron 軟體定義網路:網段、路由、防火牆 VPC VPC Virtual Network
    Cinder 區塊儲存:可掛載、可搬移的持久磁碟 EBS Persistent Disk Managed Disks
    Octavia 負載平衡即服務(LBaaS) ELB Cloud Load Balancing Load Balancer
    Barbican 金鑰、憑證與機密集中管理 Secrets Manager Secret Manager Key Vault
    Heat 宣告式資源編排(IaC) CloudFormation Infrastructure Manager Bicep / ARM
    Magnum 代管 Kubernetes 叢集 EKS GKE AKS
    Horizon 雲資源的網頁管理介面 Console Cloud Console Portal

    點服務名稱可以直接跳到認識它的那一天。

    還沒拼上的積木¶

    同一盒積木裡還有更多——這些本課程沒有部署,想擴充你的雲時就從這裡挑:

    服務 它給你什麼 AWS GCP Azure
    Swift 物件儲存 S3 Cloud Storage Blob Storage
    Manila 共享檔案系統 EFS Filestore Azure Files
    Designate DNS 代管 Route 53 Cloud DNS Azure DNS
    Trove 資料庫即服務 RDS Cloud SQL Azure Database
    Zun 容器即服務(不經 K8s) Fargate Cloud Run Container Instances
    Ironic 裸機佈建與生命週期管理 EC2 Bare Metal Bare Metal Solution Azure BareMetal
    Telemetry 計量、監控與告警 CloudWatch Cloud Monitoring Azure Monitor
    CloudKitty 用量計費與費率管理 Cost Explorer Cloud Billing Cost Management
    Masakari 虛擬機高可用與自動復原 (EC2 內建自動復原) (內建即時遷移) (內建服務修復)

    每一個的定位與「什麼時候會需要」,都整理在 Day 11 · 服務全景圖。

    課程路徑(Day 0 → 11)¶

    每一天一份 runbook,固定格式:原理 → 可照抄的步驟 → 驗收 checkpoint → 踩雷記錄。所有指令都在真實環境跑過。

    Day 主題 里程碑
    0 Azure lab 環境 支援巢狀虛擬化的 VM + 成本控管
    1 Kolla-Ansible 部署核心服務 Keystone/Glance/Nova/Neutron/Horizon
    2 OpenStack 資源全流程 純 CLI 開出可 SSH 的 VM
    3 Cinder 區塊儲存 volume 掛載、boot from volume
    4 Octavia 負載平衡 LB 建置全流程、round-robin 驗證
    5 Barbican 秘密管理 + Heat 編排 secret 存取往返、HOT stack
    6 Cluster API 管理叢集 kind + CAPI/CAPO controllers
    7 Magnum + CAPI driver 整合 ClusterTemplate 就緒
    8 端到端開出 workload cluster nodes Ready + LB + PVC 三項驗收
    9 Day-2 維運 滾動升版、node group、autoscaler
    10 Terraform 接管 + 拆除演練 HCL 管 network/VM/LB
    11 後日談:服務全景圖 用過的 11 個服務盤點 + 沒用到的版圖

    鎮館之寶¶

    Cluster API 的官方標誌:大龜馱小龜馱更小的龜,殼上都是 Kubernetes 的舵輪。官方副標一句話講完整個架構哲學——

    "It's Kubernetes all the way down."(一路往下,全是 Kubernetes)
